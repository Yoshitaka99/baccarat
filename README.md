# Baccarat Road（バカラ罫線ツール）

ブラウザだけで使えるバカラ罫線スコアボードです。

- **5 つの罫線**：大路（Big Road）・珠盤路（Bead Plate）・大眼仔（Big Eye Boy）・小路（Small Road）・甲由路（Cockroach Pig）
- **ドラゴン対応**：6 連勝以上のドラゴンテール（L 字折り返し）＋ ドラゴン発生中バッジ自動表示
- **特別役・サイドベット**：B ペア / P ペア / ドラゴン 7 / パンダ 8 / スーパー 6 / ナチュラル / 連続タイ
- **問路（次に出たら？）**：次がバンカー／プレイヤーだった場合の下三路予測と点滅プレビュー
- **30 秒ルールガイド**：画面右上の「？ ルール・見方」から確認可能
